# DS 202 Git collaboration sandbox

A classroom exercise in Git collaboration for DS 202 at Iowa State University.
This repository is a fork of [DS202-at-ISU/ds202-sandbox](https://github.com/DS202-at-ISU/ds202-sandbox).

The exercise practiced editing Markdown and collaborating through Git. It is
retained as coursework history and is no longer maintained.

For current projects and research, see [my GitHub profile](https://github.com/AkshatValse)
and [akshatvalse.com](https://akshatvalse.com).
